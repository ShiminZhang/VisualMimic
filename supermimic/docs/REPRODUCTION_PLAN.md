# Reproduction steps

Prepare the G1 motion clips at 50 Hz. Check the input joint order, root quaternion convention and CPU forward kinematics. Build the motion library, run the simulator to collect transitions, train the world model and policy, then evaluate complete clips from their initial frames. The [training guide](../README.md) lists the entry points.
